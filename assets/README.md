# VibeDebt Assets

- `mermaid.min.js`: Mermaid 11.12.2, bundled for offline dashboards under the MIT license (retained in `mermaid.LICENSE`). No external CDN requests are made by generated HTML dashboards, keeping the Observatory hermetic and private.

- `demo.gif`: 12-second terminal-to-observatory showcase demonstrating mapping, synthesized characterization tests, and transactional rollback on fault injection.
- `social-preview.png`: 1280x640 OpenGraph social card for repository sharing.
