# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-11-16

### Added
- **Codebase Cartographer (`vibedebt map`)**: AST dependency scanner and smell detectors for duplicated logic, orphaned React state, and divergent API endpoints.
- **Behavioral Test Synthesizer (`vibedebt anchor`)**: Black-box characterization generator targeting public boundaries and routes (Vitest & Playwright).
- **Architectural Healer (`vibedebt heal`)**: Atomic AST domain-layer extractor with transactional in-memory planning and automatic byte-for-byte rollback.
- **Self-Contained Architecture Observatory**: Offline HTML visualizer with embedded Mermaid runtime and interactive filtering (`vibedebt-dashboard.html`).
- **Dry-Run Preview**: In-memory refactoring planner emitting unified diffs without modifying disk.
- **RealWorld Benchmark Generalization**: Portability validation on `react-typescript-realworld-example-app` with Token-to-Bearer fault injection testing.
